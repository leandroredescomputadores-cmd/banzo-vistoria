# Banzo Vistoria 0.4.3 — prévia de localização

- Adicionada miniatura do OpenStreetMap na etapa de localização quando latitude e longitude válidas estiverem disponíveis.
- Adicionada a mesma prévia na ficha de detalhes da ocorrência.
- Botão abre a coordenada no Google Maps por link HTTPS.
- Sem dependência de chave de API do Google Maps.
- A miniatura precisa de internet; dados de GPS continuam salvos localmente.
- A compilação precisa ser confirmada no GitHub Actions antes de instalar o APK.
